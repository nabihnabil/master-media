# استوديو حصص الماستر

مصدر محرّر الشرائح وغرف مشاركة الطلبة للدكتور نبيل نبيه.

- البرنامج على GitHub Pages: https://nabihnabil.github.io/master-media/
- لوحة الإدارة: https://nabih-master-studio.flab2025.chatgpt.site/
- عرض الحصة المشتركة: https://nabihnabil.github.io/master-media/lessons/session-00-slides.html

## التشغيل الحالي

GitHub يحفظ المصدر ويستضيف البرنامج عبر Pages. المحرّر وقاعدة البيانات ورفع الوسائط والتفاعل المباشر تعمل على الاستضافة الحالية (Cloudflare Workers عبر Sites، مع D1 وR2). هذا ليس تطبيقًا ثابتًا يمكن تشغيل خلفيته على GitHub Pages وحده. لا يحتاج الاستخدام الحالي إلى Hostinger.

حساب التعديل المطلوب هو `jetnabih@gmail.com` عبر تسجيل الدخول إلى ChatGPT بالبريد نفسه. يحتفظ حساب المالك الأصلي أيضًا بصلاحيات الإدارة. لا توجد كلمات مرور في هذا المستودع.

## مسار الاستخدام

1. افتح لوحة الإدارة وسجّل الدخول.
2. عدّل الشريحة ثم احفظ التعديلات.
3. اختر «نشر نسخة الطلبة» لتحديث العرض العام.
4. اختر «بدء حصة مباشرة» وشارك رابط انضمام الطلبة.
5. افتح الإجابات واعرض النتائج وتابع طلبات التدخل من لوحة الأستاذ.

محتوى العروض المعدّل يُحفظ في قاعدة البيانات، ولا يستبدله رفع المصدر إلى GitHub. `lib/seed.json` يحتوي المحتوى الأولي فقط. صدّر العروض من لوحة الإدارة لنسخها احتياطيًا. لا ترفع أسماء المشاركين أو إجاباتهم أو ملفات تصديرهم إلى المستودع العام.

## ملاحظات التطوير والنقل

توجد نقطة التحقق من صلاحية الأستاذ في `lib/admin.ts`. تعتمد على هوية موثقة يضيفها مضيف Sites؛ لا تعتمد على هذه الترويسات مباشرة عند النقل إلى خادم عام آخر. يحتاج النقل إلى Hostinger إلى تكييف المصادقة والتخزين وقاعدة البيانات أولًا.

لم تُضمّن هوية مشروع الاستضافة ولا ملفات التشغيل المحلية أو البيانات أو الأسرار. إعداد التشغيل الخاص بالمضيف يبقى في نسخة العمل الأصلية. يتطلب البناء إعداد المضيف المناسب.

## تجربة الشاشتين

اختر «تجربة الشاشتين» من المحرّر لإنشاء حصة تجريبية، أو من لوحة الحصة لفتحها جنبًا إلى جنب. تستخدم جهة الطالب جلسة تجريبية مستقلة، وتبقى صلاحية الأستاذ محمية.
